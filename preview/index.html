🚀 Running the Real Application

To run the actual application with full functionality:

  • Navigate to the repository directory
  • Run npm ci to install dependencies
  • Create .env file with Supabase credentials
  • Apply database migrations
  • Run npm run dev to start the dev server
  • Open http://localhost:5173 in your browser

See VERIFICATION_GUIDE.md for detailed step-by-step instructions.

📋 Key Features

  • Dual Login: Separate experiences for employees and admins
  • Single Auth: Unified Supabase authentication system
  • Onboarding: Required profile completion for new users
  • Role-based Routing: Automatic routing based on user role
  • Shift Management: Day and overnight shift support
  • Admin Tools: Automated system checks and safe auto-fixes
  • Mobile-First: Responsive design optimized for mobile devices
  • Security: Row Level Security (RLS) on all tables

🎨 Design System

Colors:

  • Primary: Cyan (#06b6d4) - Employee actions
  • Secondary: Slate Blue (#475569) - Backgrounds
  • Dark: Slate Dark (#1e293b) - Admin UI
  • Warning: Gold (#fbbf24) - Admin warnings

Typography: System UI font stack

Mobile-First: Optimized for 375px+ screens

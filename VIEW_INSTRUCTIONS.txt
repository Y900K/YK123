🎯 TWO OPTIONS TO VIEW THE APPLICATION:

┌────────────────────────────────────────────────────────────────┐
│ OPTION 1: UI PREVIEWS (Fastest - No Setup)                    │
└────────────────────────────────────────────────────────────────┘

1. Navigate to the preview folder:
   $ cd preview

2. Open index.html in your browser:
   - Mac: $ open index.html
   - Linux: $ xdg-open index.html
   - Windows: Double-click index.html

3. Click through all 6 page previews:
   ✓ Choose Login
   ✓ Employee Login
   ✓ Admin Login
   ✓ Onboarding
   ✓ Dashboard
   ✓ Admin Test Center

✅ What you'll see: Design, layout, colors, interactions
❌ What won't work: Real auth, database, routing

┌────────────────────────────────────────────────────────────────┐
│ OPTION 2: FULL APPLICATION (Complete Functionality)           │
└────────────────────────────────────────────────────────────────┘

1. Run the setup script:
   $ chmod +x demo-setup.sh
   $ ./demo-setup.sh

2. Configure .env with Supabase credentials
   (See VERIFICATION_GUIDE.md for details)

3. Apply database migrations in Supabase SQL Editor
   (7 migration files in migrations/ folder)

4. Start the dev server:
   $ npm run dev

5. Open browser:
   http://localhost:5173

✅ What you'll get: Everything works!
✅ Full authentication, database, routing, forms, etc.
